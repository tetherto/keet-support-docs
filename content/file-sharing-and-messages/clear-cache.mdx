### How can I clear the group cache to save space?

To clear cached data for a specific group, open its settings and tap **‘Clear cache’** to delete shared files.
This removes files only - all text messages will remain intact.

<Tabs items={["Desktop", "Mobile"]}>
<Tab value="Desktop">

Go to the group for which you would like to clear the file cache.

Click '...' button and select '**Clear Cache**':

![Click '...' button and select 'Clear Cache':.](/images/file-sharing-and-messages/clear-cache/desktop-button-clear-cache.png "Clear Cache 🧹 · Desktop")

Confirm the removal when prompted. 

![Confirm the removal when prompted.](/images/file-sharing-and-messages/clear-cache/desktop-confirm-removal-prompted-2.png "Clear Cache 🧹 · Desktop")

Please note: this action deletes the files **only from your current device -** they may remain on other peers’ devices.
You can reupload the files later if other users haven’t deleted them on their end.

![You can reupload the files later if other users haven’t deleted them on their end.](/images/file-sharing-and-messages/clear-cache/desktop-reupload-files-later-other-users-3.png "Clear Cache 🧹 · Desktop")

</Tab>
<Tab value="Mobile">

Go to the group for which you would like to clear the file cache.

Open '**Group options'** and tap '**Clear Cache**':

![Open 'Group options' and tap 'Clear Cache':.](/images/file-sharing-and-messages/clear-cache/mobile-group-options-clear-cache-4.png "Clear Cache 🧹 · Mobile")

Confirm the removal when prompted. 

![Confirm the removal when prompted.](/images/file-sharing-and-messages/clear-cache/mobile-confirm-removal-prompted-5.jpg "Clear Cache 🧹 · Mobile")

Please note: this action deletes the files **only from your current device -** they may remain on other peers’ devices.
You can reupload the files later if other users haven’t deleted them on their end.

![You can reupload the files later if other users haven’t deleted them on their end.](/images/file-sharing-and-messages/clear-cache/mobile-reupload-files-later-other-users-6.jpg "Clear Cache 🧹 · Mobile")

</Tab>
