## How can I remove messages and files in Keet?

### Delete a sent message

Peers can delete any messages or files they’ve sent in a group - regardless of how long ago they were sent.
Users with Administrator and Moderator roles can also [remove messages sent by others](/keet-groups/group-member-roles).
See below how to remove messages or media from your device:

<Tabs items={["Desktop", "Mobile"]}>
<Tab value="Desktop">

Go to the message you would like to remove.

Click the three dots next to the message / select '**Delete Message**'.

![Click the three dots next to the message / select 'Delete Message'.](/images/file-sharing-and-messages/deleting-files-and-messages/desktop-three-dots-next-message-delete.png "Deleting Files and Messages 🗑️ · Desktop")

<Callout type="warn">
Please note that the message removal is permanent and cannot be undone 🗑️
</Callout>

![Please note that the message removal is permanent and cannot be undone 🗑️.](/images/file-sharing-and-messages/deleting-files-and-messages/desktop-please-note-message-removal-permanent-2.png "Deleting Files and Messages 🗑️ · Desktop")

The removed message will be shown in the chat as **'Message deleted'.**

</Tab>
<Tab value="Mobile">

Go to the message you would like to remove.

Long-press the message / select '**Delete**'. 

![Long-press the message / select 'Delete'.](/images/file-sharing-and-messages/deleting-files-and-messages/mobile-long-press-message-delete-3.jpg "Deleting Files and Messages 🗑️ · Mobile")

<Callout type="warn">
Please note that the message removal is permanent and cannot be undone 🗑️
</Callout>

![Please note that the message removal is permanent and cannot be undone 🗑️.](/images/file-sharing-and-messages/deleting-files-and-messages/mobile-please-note-message-removal-permanent-4.jpg "Deleting Files and Messages 🗑️ · Mobile")

The removed message will be shown in the chat as **'Message deleted'.**

![The removed message will be shown in the chat as 'Message deleted'.](/images/file-sharing-and-messages/deleting-files-and-messages/mobile-removed-message-will-shown-chat-5.jpg "Deleting Files and Messages 🗑️ · Mobile")

</Tab>
</Tabs>

### Remove files or media from your device

You can remove specific files and media in a chat to save space on your device.

<Tabs items={["Desktop", "Mobile"]}>
<Tab value="Desktop">

Go to the file you want to remove from your device.

Click '...' / '**Clear cache':**<br />

![Click '...' / 'Clear cache':.](/images/file-sharing-and-messages/deleting-files-and-messages/desktop-clear-cache-6.png "Deleting Files and Messages 🗑️ · Desktop")

You will be prompted to confirm file removal:

![You will be prompted to confirm file removal:.](/images/file-sharing-and-messages/deleting-files-and-messages/desktop-will-prompted-confirm-file-removal-7.png "Deleting Files and Messages 🗑️ · Desktop")

Please note: this deletes the file **only from your device** — it may remain on other peers’ devices.
You can reupload it later if other users haven’t deleted it on their end.

![You can reupload it later if other users haven’t deleted it on their end.](/images/file-sharing-and-messages/deleting-files-and-messages/desktop-reupload-later-other-users-haven-8.png "Deleting Files and Messages 🗑️ · Desktop")

</Tab>
<Tab value="Mobile">

Go to the file you want to remove from your device.

Long-press the message and select '**Clear cache**'.

![Long-press the message and select 'Clear cache'.](/images/file-sharing-and-messages/deleting-files-and-messages/mobile-long-press-message-clear-cache-9.jpg "Deleting Files and Messages 🗑️ · Mobile")

Please note: this deletes the file **only from your device** — it may remain on other peers’ devices.
You can reupload it later if other users haven’t deleted it on their end.

</Tab>
</Tabs>

### Invisible message removal

The removed message is always shown in the chat as '**Message deleted**'. 
It is currently not possible to delete without a trace or recall message sending.
