## What is a language pack?

Whenever you [translate a message](/file-sharing-and-messages/translate-messages) using a language pair you haven't used before, Keet downloads a small language pack for that pair - the English and French pack, for example, is roughly 25 MB. Once downloaded, the pack is kept on your device so the same pair doesn't need to be downloaded again.

Each pack works in **both directions**, so the English and French pack covers English to French as well as French to English. You only download a pair once, no matter which way round you translate.

If you've translated messages between many different languages, these packs can add up. The **Language packs** screen lets you see exactly what's installed and remove packs you no longer need.

<Callout type="info">
'**Language**' settings were renamed to '**Language and translations**' to reflect message translation settings living alongside your app language. 🌐
</Callout>

## Delete a language pack

Select the delete icon next to any pair to remove it from your device.

<Tabs items={["Desktop", "Mobile"]}>
<Tab value="Desktop">

A confirmation dialog opens - select '**Cancel**' to keep the pack, or '**Delete**' to remove it.

![Delete language pack? Cancel keeps the pack, Delete removes it.](/images/file-sharing-and-messages/language-packs/desktop/delete-confirm.png "Language Packs 📦 · Desktop")

</Tab>
<Tab value="Mobile">

A confirmation sheet opens - tap '**Cancel**' to keep the pack, or '**Delete**' to remove it.

![Delete language pack? Cancel keeps the pack, Delete removes it.](/images/file-sharing-and-messages/language-packs/mobile/delete-confirm.png "Language Packs 📦 · Mobile")

</Tab>
</Tabs>

Once deleted, the pack is removed from your device and the list and total storage update immediately. You can always download the same pair again later by translating a message with it.

<Callout type="warn">
A pack can't be deleted while it's still downloading. If you try, Keet asks you to try again once the download finishes. ⚠️
</Callout>

<Callout type="info">
Language packs are downloaded and stored per device, so deleting one frees up storage on that device only. 🔗
</Callout>
