## How can I share files and media in Keet?

Open a chat and click the '**Attach a file**'[🔗] button:

![Open a chat and click the 'Attach a file' button.](/images/file-sharing-and-messages/sharing-files-and-media/chat-attach-file-button.png "Sharing Files and Media 🗃️")

When prompted, allow Keet to access your media files.

Select the files you want to share with your peers, or drag and drop them into the chat window (on desktop).

![Select the files you want to share with your peers, or drag and drop them into the chat window (on desktop).](/images/file-sharing-and-messages/sharing-files-and-media/files-want-share-peers-drag-2.png "Sharing Files and Media 🗃️")

Click '**Send now' \[**▶️**]** button when the files are ready. Once uploaded, all group participants will have access to the shared files.

<Callout type="info">
Since it’s peer-to-peer, both devices need to be online for smooth and fast file transfer. 🟢
</Callout>

### Receive and download files

Shared files appear in the chat feed. To preview, click images, videos, or supported file types (e.g., .txt, .pdf). To download a file, click the three dots next to it and select '**Save to files**'.

![Shared files appear in the chat feed. To preview, click images, videos, or supported file types (e.g., .txt….](/images/file-sharing-and-messages/sharing-files-and-media/shared-files-appear-chat-feed-3.png "Sharing Files and Media 🗃️")

#### Monitor file transfer status

On the desktop,  the download process status bar appears in the top left corner of the app: 

![On the desktop, the download process status bar appears in the top left corner of the app:.](/images/file-sharing-and-messages/sharing-files-and-media/desktop-download-process-status-bar-4.png "Sharing Files and Media 🗃️")

When the file download is complete, the status will update:

![When the file download is complete, the status will update:.](/images/file-sharing-and-messages/sharing-files-and-media/file-download-complete-status-will-5.png "Sharing Files and Media 🗃️")

Hover your mouse over the shared file to see its upload/download speed and the number of peers sharing it.

![Hover your mouse over the shared file to see its upload/download speed and the number of peers sharing it.](/images/file-sharing-and-messages/sharing-files-and-media/hover-mouse-over-shared-file-6.png "Sharing Files and Media 🗃️")

<Callout type="info">
The ‘Seeds’ icon shows how many people have parts of the shared file. 
 To finish downloading, the sender may need to be online. 👥
</Callout>

#### How to speed up the file transfer?

Keep the chat open on both devices while transferring files to ensure seamless communication.

<Callout type="info">
Upload speed depends on your and the seed's internet connection. 📡
</Callout>
