# Sharing Files and Media 🗃️

### How can I share files and media in Keet?

Open a chat and click the '**Attach a file' \[**��] button: 

![](/files/zxrf2pxArH7JDn7T3Lcm.png)

When prompted, allow Keet to access your media files.

Select the files you want to share with your peers, or drag and drop them into the chat window (on desktop).

![](/files/pe5KMruwKwNR8vPK2WKL.png)

Click '**Send now' \[**▶️**]** button when the files are ready. Once uploaded, all group participants will have access to the shared files.

<Callout type="info">
Since it’s peer-to-peer, both devices need to be online for smooth and fast file transfer. 🟢
</Callout>

---

### Receive and download files

Shared files appear in the chat feed. To preview, click images, videos, or supported file types (e.g., .txt, .pdf). To download a file, click the three dots next to it and select '**Save to files**'.

![](/files/IaTScYwipSvubyIrDFIp.png)

---

### Monitor file transfer status

On the desktop,  the download process status bar appears in the top left corner of the app: 

![](/files/QK7gCvLuyRP3cpJZ88tN.png)

When the file download is complete, the status will update:

![](/files/6lc8T3MFzdg3T81WhORm.png)

Hover your mouse over the shared file to see its upload/download speed and the number of peers sharing it.

![](/files/UAOMvYAU5Xw0nLLtutQH.png)

<Callout type="info">
The ‘Seeds’ icon shows how many people have parts of the shared file. 
 To finish downloading, the sender may need to be online. 👥
</Callout>

---

### How to speed up the file transfer?

Keep the chat open on both devices while transferring files to ensure seamless communication.

<Callout type="info">
Upload speed depends on your and the seed's internet connection. 📡
</Callout>
