The app is available on Windows, macOS, Linux, Android, iOS, and GrapheneOS, so you can use it on almost any device you have.

## Desktop Installation

<Tabs items={["Windows", "MacOS", "Linux"]}>
<Tab value="Windows">

* Download the Windows installer from [https://keet.io/download/](https://keet.io/download/) :

![Keet download page with the Windows installer on keet.io.](/images/installation-and-setup/installation/windows-installer-download.png "Installation · Windows")

* Launch the **Keet.msix** installer and follow the on-screen instructions.
* Allow pear-runtime access to public and private networks on your PC during the installation.

</Tab>
<Tab value="MacOS">

![Keet download page with the macOS DMG installer on keet.io.](/images/installation-and-setup/installation/macos-dmg-download.png "Installation · MacOS")

* Download Keet for macOS from [https://keet.io/download/](https://keet.io/download/) 
* Open the downloaded **Keet.dmg** file.
* Drag the app to the Applications folder and launch it.<br />

<Callout type="info">
On a **standard (non-admin) account** — such as a child's account or a shared/work Mac — apps in the `/Applications` folder can't auto-update without an administrator. If you don't have admin rights, install Keet in your personal `/Users/UserName/Applications` folder instead, and follow [Auto-Updates on macOS](/technical-support-and-troubleshooting/auto-updates-macos).
</Callout>

</Tab>
<Tab value="Linux">

* Download Keet for Linux from [https://keet.io/download/](https://keet.io/download/)
* Extract the **Keet.tar.gz** file and run the AppImage to start the application.
* You can directly download Keet from [Snap Store](http://snapcraft.io/keet) on Linux Ubuntu.

<Callout type="info">
For all Linux systems, you may need to install additional libraries like [<kbd>libgtk-4</kbd> or <kbd>libnss3</kbd>](https://gtk.org/docs/installations/linux/).

Running AppImage packages also requires <kbd>libfuse</kbd> to be installed.
</Callout>

</Tab>
</Tabs>

## Mobile installation

<Tabs items={["Android", "iOS"]}>
<Tab value="Android">

Install Keet from the [Google Play Store](https://play.google.com/store/apps/details?id=io.keet.app\&pcampaignid=web_share) or visit [https://keet.io/download/](https://keet.io/download/) and click on 'Get it on Google Play'. 

![Google Play Store listing for Keet on Android.](/images/installation-and-setup/installation/android-google-play-listing.png "Installation · Android")

Alternatively, you can find the latest APK on our [GitHub](https://github.com/holepunchto/keet-mobile-releases/releases).

</Tab>
<Tab value="iOS">

Install Keet from the [App Store](https://apps.apple.com/lu/app/keet-by-holepunch/id6443880549) or visit [https://keet.io/download/](https://keet.io/download/) and click on 'Download on the App Store'.

![App Store listing for Keet on iOS.](/images/installation-and-setup/installation/ios-app-store-listing.png "Installation · iOS")

</Tab>
</Tabs>

## Platform support

| Platform | Version | Architecture |
| --- | --- | --- |
| Android | **10**+ | `arm` `arm64` |
| iOS | **16.6**+ | `arm64` `x64 (simulator)` |
| macOS | **12.0**+ | `arm64` `x64` |
| Windows | **Windows 10**+ | `x64` |
| Windows | **Windows 11**+ | `arm64` |
| Linux | **Linux 5.15+**, GNU C Library 2.3+ | `arm64` `x64` |
| Linux | **Linux 5.10+**, musl 1.2+ | `arm64` `x64` `mips` `mipsel` |

<Callout type="info">
Not sure which architecture your device has? 🔎 

Just look up your device model online or check your system info, then match it to the table above.
</Callout>
