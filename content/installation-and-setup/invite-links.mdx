You can be invited into Keet in three ways:

* Click a Keet room link (`https://keet.io/join#...`)
* Scan a Keet room QR code
* Scan a user's profile QR code

All three work the same way. If Keet is already installed, you're taken straight into the room or chat. If it isn't installed yet, you're guided to download the app first — once you open it, you land right back in the room or chat you were invited to, with no need to click the link or scan the code again.

## If Keet is already installed

The link or QR code opens Keet directly and continues into the intended action — [joining the group](/keet-groups/joining-groups) or starting the chat.

## If Keet is not installed

The link or QR code opens a join page in your browser instead. This page explains what you're joining and offers two options: **Open Keet** (if you already have it) or **Download Keet** to install it first.

Once Keet is installed and you open it, it continues straight into the room or chat you were invited to — you don't need to click the invite link again.

<Callout type="info">
If opening the app automatically doesn't work, you can always paste the `https://keet.io/join#...` link into the **Search or paste invite link** field inside Keet — the same way it works on mobile.
</Callout>
