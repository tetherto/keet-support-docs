Screen-sharing on a call, presenting from your laptop, or just working somewhere your screen isn't private — none of those should mean exposing every room name and message on your screen. **Private Mode** masks your chat list and message content on-screen while you keep using Keet normally underneath.

## Turn on Private Mode

<Tabs items={["Desktop", "Mobile"]}>
<Tab value="Desktop">

1. Click your avatar to open '**Profile**', and toggle on '**Private Mode**':

   ![The Private Mode toggle sits in the Profile panel, just below your bio.](/images/security-and-privacy/private-mode/desktop/profile-panel-toggle.png "Private Mode 🙈 · Desktop")
2. A '**Private Mode**' confirmation appears near the top of the window, showing '**On**':

   ![A confirmation banner near the top of the window confirms Private Mode is on.](/images/security-and-privacy/private-mode/desktop/private-mode-on-confirmation.png "Private Mode 🙈 · Desktop")

</Tab>
<Tab value="Mobile">

1. Go to '**Profile**' and toggle on '**Private Mode**':

   ![The Private Mode toggle sits on your Profile page, just below your bio.](/images/security-and-privacy/private-mode/mobile/profile-toggle.png "Private Mode 🙈 · Mobile")
2. A '**Private Mode**' confirmation shows '**On**', and your chat list is immediately masked:

   ![A confirmation banner confirms Private Mode is on, and the chat list behind it is already masked.](/images/security-and-privacy/private-mode/mobile/private-mode-on-masked-list.png "Private Mode 🙈 · Mobile")

</Tab>
</Tabs>

<Callout type="info">
Turning Private Mode off shows the same confirmation with '**Off**' instead — nothing else changes until you toggle it.
</Callout>

## What gets masked

With Private Mode on, Keet hides anything that could identify who you're talking to or what's being said. The layout stays the same, so the app is still easy to use — just unreadable at a glance.

### Your chat list

* Room and DM names are replaced with a generic label like '**Group chat**' or '**DM chat**'.
* Avatars and images are replaced with plain placeholder circles.
* Message previews are replaced with generic text like '**You received a message**'.
* Timestamps, unread counts, and mentions stay visible, so the list is still usable.

### Inside a chat

* Sender names and avatars are hidden, so messages can't be tied to a person at a glance.
* Message text is replaced with a generic placeholder, like '**You received a message**' or '**Message sent**'.
* Media thumbnails are replaced with a placeholder too, instead of showing the original image or video.
* A '**Turn off private mode**' banner sits at the top of the chat the whole time, so you're never more than one tap away from normal view — see [Turn off Private Mode from inside a chat](#turn-off-private-mode-from-inside-a-chat) below.
* On mobile, a hint under the banner — '**Tap a message to view original content**' — reminds you how to check any message.

## Reveal one message at a time

Need to actually read a message without leaving Private Mode? You can reveal it on its own, without unmasking the rest of the chat.

<Callout type="warn">
Revealing a single message is currently available on mobile only — desktop support is coming soon.
</Callout>

1. Tap a masked message to open it in a '**View message**' sheet, set to '**Manual reveal**' by default — it shows the real message once, then masks it again once you back out:

   ![The View message sheet, set to Manual reveal, shows the message's real sender and text.](/images/security-and-privacy/private-mode/mobile/view-message-manual-reveal.png "Private Mode 🙈 · Mobile")
2. Switch the mode to '**Always reveal**' if you'd rather that message stay unmasked going forward, instead of re-hiding it every time:

   ![Switching the View message sheet to Always reveal keeps that message unmasked going forward.](/images/security-and-privacy/private-mode/mobile/view-message-always-reveal.png "Private Mode 🙈 · Mobile")

<Callout type="info">
Revealing a message only affects that message — the rest of the chat, and the rest of your chat list, stay masked.
</Callout>

## Turn off Private Mode from inside a chat

<Callout type="warn">
Turning Private Mode off from inside a chat is currently available on mobile only — desktop support is coming soon.
</Callout>

1. Tap '**Turn off private mode**' at the top of any chat:

   ![The Turn off private mode banner sits at the top of the chat while Private Mode is on.](/images/security-and-privacy/private-mode/mobile/masked-room.png "Private Mode 🙈 · Mobile")
2. Confirm in the '**Turn off Private mode?**' sheet. '**Cancel**' keeps Private Mode on; '**Yes**' restores normal view everywhere:

   ![A confirmation sheet asks you to confirm before turning Private Mode off.](/images/security-and-privacy/private-mode/mobile/turn-off-confirmation-modal.png "Private Mode 🙈 · Mobile")

You can also turn Private Mode off from '**Profile**' at any time, the same way you turned it on — that works on both desktop and mobile.

## Keyboard and screen reader support

The '**Private Mode**' toggle in Profile works without a mouse: '**Tab**' (or '**Shift+Tab**' to go back) moves focus to it, and '**Enter**' or '**Space**' turns it on or off. Keyboard support for revealing a message and turning Private Mode off from inside a chat will be documented once desktop support ships.

<Callout type="info">
Screen readers don't announce a hidden message's real content — they read the same placeholder text sighted users see, until that message is revealed.
</Callout>
